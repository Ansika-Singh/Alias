Alias✨
AI-Powered Facial Attendance Tracking System
Eliminate roll calls. Automate attendance. Save every minute of class.
📌 Overview
Alias is an intelligent, face-recognition-based attendance management system designed for schools, colleges, and offices. Students or employees simply walk in front of a camera — Alias identifies them, logs their attendance, tracks their presence period-by-period, and automatically notifies the concerned teacher or manager.
No more 10-minute roll calls. No more proxy attendance. No more manual registers.
🚨 The Problem
In a typical school or college:
10–15 minutes per class are wasted on vocal roll calls
For 6 periods a day → ~1 hour of teaching time lost daily
Proxy attendance is rampant and hard to detect
Teachers manually compile absentee reports — time-consuming and error-prone
No real-time visibility for subject teachers or administrators
Alias solves all of this.
✅ Core Features
👤 Facial Recognition & Identification
Real-time face detection using camera feed
Matches faces against pre-enrolled student/employee database
Works even with glasses, masks (partial), or slight angle variations
Multi-face detection — marks multiple people simultaneously
🗓️ Timetable-Aware Tracking
System is fed the day's timetable at the start of each day
Knows which period is running, which subject, and which teacher is responsible
Attendance is recorded per period, not just per day
⏱️ Time-in / Time-out Logging
Tracks exact entry and exit times for each individual
Records total duration spent in class for the day
Detects mid-class exits and logs them
📊 Absentee & Attendance Reports
Automatically generates and sends:
✅ List of present students per period
❌ List of absentees per period
⏳ Duration each student was present
📋 Which periods were skipped by each student
📈 Cumulative attendance % per student
📨 Automated Notifications
Email / SMS / portal alert sent directly to the subject teacher at the start or end of each period
Parents notified if a student is absent or leaves early
Admin dashboard receives a full-day summary report
Late arrivals flagged automatically
🧑‍💼 Student / Employee Database Management
Admin panel to register new students/employees with photo upload
Stores: Name, ID, Department/Class, Contact, Parent contact, Subject enrollments
Bulk upload via CSV for entire batches
🔒 Anti-Proxy & Security
Detects photo spoofing (liveness detection)
Flags unrecognized faces attempting entry
Logs all access attempts with timestamps
📅 Timetable Integration
Import timetable via Excel/CSV or manual entry
Supports rotating schedules, lab sessions, and special periods
Handles substitute teacher assignments
📱 Teacher & Admin Dashboard
Subject teachers see live attendance for their ongoing class
Admins view institution-wide attendance heatmaps
Filter by: date, class, subject, student, department
Export reports as PDF / Excel
🔔 Smart Alerts
Notify teacher if attendance drops below threshold (e.g., < 75%)
Alert admin if a student has been absent 3+ consecutive days
Flag students with suspicious patterns (always absent for one subject).
🚀 Getting Started
Register students/employees via the admin panel (photo + details)
Upload today's timetable (or sync from existing schedule)
Start the camera at entry points (classroom door / office gate)
Alias does the rest — detects, logs, reports, notifies ✅.
